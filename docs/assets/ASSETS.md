# Assets Guide

This folder contains visual assets for the Imagenix README and documentation.

## Required Assets

### Logo
- `logo.png` - Main Imagenix logo (recommended: 200x200 or 400x400 PNG with transparency)

### Screenshots
Place the following screenshots in the `screenshots/` folder:

| Filename | Description | Recommended Size |
|----------|-------------|------------------|
| `dashboard.png` | Main dashboard showing project list | 1280x720 |
| `dataset-gallery.png` | Dataset page with image thumbnails | 1280x720 |
| `annotation-editor.png` | Annotation canvas with bounding boxes | 1280x720 |
| `augmentation-studio.png` | Augmentation settings panel | 1280x720 |
| `export-dialog.png` | Export format selection dialog | 800x600 |

## Capture Tips

1. Use a clean browser (incognito mode) to avoid extensions
2. Set viewport to 1280x720 for consistency
3. Use sample data that showcases features
4. Ensure no sensitive information is visible
5. Compress images to keep file size reasonable (<500KB each)

## Tools

- **macOS**: Cmd+Shift+4 for selection, Cmd+Shift+5 for options
- **Windows**: Win+Shift+S for Snip & Sketch
- **Chrome DevTools**: Device toolbar for consistent viewport sizes
